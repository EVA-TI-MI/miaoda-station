# 妙搭小站 (Miaoda Station)

弈境棋院（AI 围棋 / AI 中国象棋 / AI 国际象棋 / AI 五子棋 / AI 黑白棋 / AI 跳棋 / AI 军棋 / AI 斗兽棋 / AI 将棋 / AI 国际跳棋）+ 更多玩法（飞行棋 / 华容道 / 数独 / 数织 / 数回 / 数桥 / 数墙 / 美术馆 / 24 点 / 猜数字 / 连连看 / 数字华容道 / 推箱子 / 2048 / 扫雷 / 跳一跳 / 俄罗斯方块 / 打砖块 / 记忆翻牌 / 打地鼠 / 小恐龙快跑 / 乒乓球）+ 腾蛇 + 墨渊阁小说阅读器。
基于 HTML5 Canvas + 原生 JavaScript 开发，**所有 AI 均在浏览器本地计算，无需后端、可离线运行（PWA）**，
可通过 pywebview 打包为 Windows 桌面应用，也可直接在浏览器中打开。

- 有声书朗读：系统语音 / 在线百度 TTS / 离线 sherpa-onnx 神经 TTS 三引擎，多音色、语速、逐段高亮、点段落朗读、录音、离线语音包导入导出
- **配套爬虫 `novel_crawler.py` v3.0**：多站点适配、异步并发、断点续传/增量更新、智能编码检测（UTF-8/GBK）、章节分页自动合并、终轮失败补抓与失败清单、TXT/EPUB 双格式导出、关键词搜索、批量清单下载、自定义代理/UA/Referer/Cookie

### 7. 效率工具
#### 7.1 番茄钟（`pomodoro.html`）
- 工作 / 短休 / 长休自动循环，环形进度 SVG 实时反馈；结束与开始均以系统语音（speechSynthesis）播报
- 工作时长、短休、长休（每 4 轮后）独立调节；今日番茄数与累计番茄数按日存档；独立倒计时模式（Tab 切换）

#### 7.2 随机抽签 · 决策器（`tool-random.html`）
- 抽签：每行一个选项，支持随机抽一个 / 不放回连续抽取 / 重置
- 幸运转盘：Canvas 扇区转盘，旋转减速后指针定胜负；选项与抽签区同源可同步
- 骰子：1-2 枚 d6、1 枚 d20、抛硬币

#### 7.3 单位换算（`tool-convert.html`）
- 长度 / 重量 / 面积 / 体积 / 温度 / 时间 / 数据 / 速度八大类，温度走专用换算公式
- 输入数值 + 选单位即时换算全部单位；点击任意结果行反向换算；科学计数法处理极大极小值

#### 7.4 密码生成器（`tool-password.html`）
- 浏览器 crypto 加密级随机数；长度 4-128、大小写 / 数字 / 符号自由勾选、可排除易混字符（0O1lI）
- 熵值与强度实时评估（极弱→极强）；一次生成 1-12 枚、逐条一键复制；纯本地不联网

#### 7.5 单词卡 · 背诵（`wordcard.html`）
- 内置四级高频词库（约 400 词）+ 自定义生词；点卡翻转看释义
- 认识进词库、不认识进错词本；按「全部 / 仅错词本 / 仅已认识」范围复习；进度与复习次数本地保存；键盘空格翻卡、方向键作答

#### 7.6 涂鸦板（`drawboard.html`）
- Canvas 画布随笔：六色可选、粗细 2–40 自由调节，随时撤销、清空
- 画作自动保存到浏览器本地（关闭重开仍在），可一键导出 PNG 下载

#### 7.7 白噪音 · 助眠（`whitenoise.html`）
- 雨声 / 海浪 / 风声 / 溪流 / 篝火 / 风扇六种环境声，全部由 Web Audio 实时合成、**不联网**
- 可同时叠加多种声音并调节总音量；浏览器原生合成，无需音频文件

### 8. 站内系统
#### 8.1 成就 · 排行榜（`stats.html`）
- 汇总全站 localStorage 最佳成绩：棋院对弈胜率、黑白棋领先数、跳棋步数、军棋/斗兽棋连胜、华容道各布局最少步、数独/数织/数回最快用时、24 点连对、猜数字最少次数、经典街机各最高分、腾蛇玩家本地排行（按 neonSnakeHighScore_*）、墨渊阁阅读时长与书架统计、番茄钟累计
- 缺失容错：无记录显示「还没有记录」；顶部四格总览（玩法数 / 有成绩项 / 总胜场 / 阅读分钟）

#### 8.2 每日挑战（`daily.html`）
- 以日期为种子生成确定性题面：每日一局固定数独（模板解 + 种子变换 + 40 洞挖空）与一关「横刀立马」华容道
- 数独点格填数、即时检查（对照种子终盘校验）；华容道以 `hrd.html?daily=1` 直连每日关卡（锁定布局、禁用切关并显示每日挑战提示）

#### 8.3 存档管理（`backup.html`）
- 一键导出全部游戏进度（localStorage 全量 JSON 文件下载），换设备不丢成绩
- 导入存档：解析 JSON 后逐键写入并提示刷新；当前存档键数与占用大小一页总览

## 技术栈
- 前端：HTML5 Canvas、原生 JavaScript（无框架依赖）
- 棋类 AI：围棋 MCTS；中国象棋/国际象棋 Negamax + Alpha-Beta + 迭代加深（PST 评估）；五子棋棋型评估 + Minimax + Alpha-Beta
- 益智：华容道 BFS（连续滑动边，标准 81 步）；数独回溯生成 + 唯一解校验；飞行棋贪心 AI 与完整规则状态机
- 桌面：pywebview + PyInstaller
- 爬虫：Python aiohttp（异步并发）+ BeautifulSoup，标准库 zipfile 生成 EPUB
- 部署：GitHub Pages（PWA）
