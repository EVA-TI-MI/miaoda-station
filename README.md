# 妙搭小站 (Miaoda Station)

弈境棋院（AI 围棋 / AI 中国象棋 / AI 国际象棋 / AI 五子棋）+ 更多玩法（飞行棋 / 华容道 / 数独 / 推箱子 / 2048 / 扫雷 / 跳一跳）+ 腾蛇 + 墨渊阁小说阅读器。
基于 HTML5 Canvas + 原生 JavaScript 开发，**所有 AI 均在浏览器本地计算，无需后端、可离线运行（PWA）**，
可通过 pywebview 打包为 Windows 桌面应用，也可直接在浏览器中打开。

## 三大板块 · 十二款游戏

### 1. AI 围棋 · 弈境（`go.html`）
- 完整规则：连通块气数计算、自动提子、禁着点（自杀）拦截、打劫（局面签名防回提）
- 9 / 13 / 19 路棋盘，让子（0–9 子）、贴目（7.5/6.5/0）
- AI：蒙特卡洛树搜索（MCTS，选择—扩展—随机模拟—回传），四档难度按时间预算迭代；含吃子优先的模拟策略
- 停一手（双方连停终局）、认输、终局标记死子 + 中国规则数子、势力可视化
- 标准 SGF 棋谱导出/复制、悔棋/重做、AI 提示、提子统计、计时、战绩、自动续局、棋盘皮肤

### 2. 象棋（`chess.html` 为二级选择页，内含两种）
进入象棋模块后可选择中国象棋或国际象棋，两者操作体验一致。

#### 2.1 AI 中国象棋 · 楚河（`xiangqi.html`）
- 完整规则：七兵种走法、蹩马腿、塞象眼、象不过河、九宫限制、飞将照面拦截、合法着法过滤
- 将军 / 将死 / 困毙判定（困毙亦负）
- AI：子力价值 + 位置表（PST）、Negamax + Alpha-Beta 剪枝、着法排序（MVV-LFA）、迭代加深 + 时间预算，四档难度
- 合法走法高亮、AI 提示、悔棋/重做、翻转棋盘、执红执黑、中文标准着法棋谱、双方吃子陈列与子力优势条
- 内置经典残局挑战、棋谱导出、计时、战绩、自动续局、棋盘皮肤

#### 2.2 AI 国际象棋（`intchess.html`）
- 完整规则：兵首步双走、斜吃、**吃过路兵（en passant）**、到底线**升变**（后/车/象/马，默认升后）；马、象、车、后、王的标准走法
- **王车易位**（长/短易位，校验空格、王不在被将、途经格不被攻击）；几何攻击判定与合法着法过滤
- 将死 / 逼和（无子可动和棋）/ 子力不足和棋判定
- AI：子力价值 + 六张位置表（PST）、Negamax + Alpha-Beta + 迭代加深，四档难度
- 代数记谱（SAN：O-O / O-O-O / 吃子 x / 升变 =Q / 将 + / 将杀 #）、合法走法高亮、悔棋/重做、AI 提示、执白执黑、吃子陈列与子力优势条、棋谱导出、计时、战绩、自动续局

### 3. AI 五子棋 · 连珠（`gomoku.html`）
- 15 路标准盘，五连判定；可选连珠禁手（黑方双三 / 双四 / 长连）
- AI：活四/冲四/活三/活二等棋型评估 + Minimax（Negamax）+ Alpha-Beta 剪枝 + 候选着法排序，四档难度
- 人机 / 双人 / AI 观战三模式、执黑执白、落子手数编号、AI 杀点提示、悔棋（人机连撤两步）/重做
- 坐标棋谱导出/复制、局势条、计时、战绩、自动续局、棋盘皮肤

### 4. 更多玩法（`fun.html` 为二级选择页，内含七款益智/休闲游戏）

#### 4.1 飞行棋（`airplane.html`）
- 四色十六机传统飞行棋：红/黄/蓝/绿四阵营、各 4 架飞机，2/3/4 人参与
- 完整规则：掷 6 起飞、掷 6 或撞下敌机再投一次；落在己方同色格向前跳 4 格；箭头格沿虚线飞跃（行走落箭头格：飞至远端后再跳 4 格进入跑道）；撞机将敌机打回机库；己方飞机可同格；终点需精确点数，超出反弹（多退少补）
- 外环 52 格 + 各方 5 格彩色跑道 + 中心终点，15×15 标准棋盘布局
- 人机对战（其余席位由贪心 AI 补位：撞机/飞跃/跳跃/起飞/到家分项评分）与同屏热座两种方式
- 逐格移动、跳跃、虚线飞跃动画；可动飞机高亮、唯一合法机自动移动、事件日志、胜利结算

#### 4.2 华容道（`hrd.html`，参考开源滑块求解器重写）
- 收录横刀立马、指挥若定、将拥曹营、齐头并进、兵分三路、雨声淅沥、左右布兵、桃花源中、小旋风共 9 道传统布局
- 触摸拖拽（支持连续多格、拐弯）、点选 + 方向按钮、键盘 WASD/方向键、点空格移动
- 步数口径：同一棋子连续滑动只计 1 步；BFS 广度优先求解器以「连续滑动」为边，横刀立马解出标准 81 步（约 0.4 秒）
- 单步提示最优走法、一键自动演示完整路线（可中途停止）、撤销、重置、计时、最佳记录本地持久化

#### 4.3 数独（`sudoku.html`，参考 sudoku.js 思路重写）
- 随机回溯生成合法终盘 + 对称挖洞，二解剪枝校验**保证唯一解**；简单/中等/困难/专家四档（40/34/30/26 枚线索）
- 数字键盘、候选笔记、即时错误检查、同行/同列/同宫高亮、相同数字高亮、剩余数字计数
- 撤销、擦除、每局 3 次提示、计时暂停、自动续玩、各难度最佳成绩；键盘 1-9/方向键/Z 撤销/N 笔记

#### 4.4 推箱子（`sokoban.html`）
- 7 道经典关卡（全部经 BFS 求解器验证可解），移动推箱、全部归位过关
- 方向键 / WASD / 方向键 + 触摸滑动；撤销、重置、上一关/下一关，每关最佳步数本地持久化

#### 4.5 2048（`2048.html`）
- 4×4 网格滑动合并相同数字，2 与 2 成 4、4 与 4 成 8，一路向 2048 进发
- 方向键 / WASD / 触摸滑动；合成 2048 后仍可继续冲击更高分，实时得分与本地最高分，失败弹窗重开

#### 4.6 扫雷（`minesweeper.html`）
- 三档难度：初级 9×9/10 雷、中级 16×16/40 雷、高级 16×30/99 雷；**首步必安全**
- 左键翻开、右键/长按插旗、旗模式切换、翻开的数字双击/连点快速展开（chord）、计时与各难度最佳成绩本地持久化

#### 4.7 跳一跳（`jump.html`）
- 按住屏幕（或空格）蓄力、松手跳出，落在下个方块即得分；等距 3D 视角，蓄力越久跳得越远
- 落在方块中心 +2 分并连击、边缘 +1 分，落入空隙即结束；最佳成绩本地持久化

### 5. 腾蛇（`snake.html`，参考开源项目增强）
- 16 款皮肤（V 键逆时针切换）、三种难度、穿墙模式、多档地图/窗口尺寸、本地排行榜、用户系统、快捷键操作
- **随机道具**：减速（时间变慢）、金身（短时穿越自身与障碍）、缩身（立即缩短 4 节），道具限时出现
- **障碍物模式**：可开关的随机障碍布局（避开出生区），增加走位挑战
- **AI 自动演示**：BFS 最短寻路 + 洪水填充逃生校验（保证安全活动空间），随时一键接管/交还（i 键）
- 局内统计：食物数、用时、长度、分数 HUD 实时展示；随分数自动加速

### 6. 墨渊阁小说阅读器（`biquge.html`，参考 tReader / Koodo Reader / foliate-js 等开源阅读器增强）
- 在线书库浏览/搜索/分类排行标签、本地账号、书架/收藏/喜欢、本地 TXT 导入（IndexedDB 自动分章）
- **阅读进度精确到章内滚动位置**（回到上次阅读处），兼容旧版进度
- **排版自定义**：行距、段间距、内容页宽、字号、三种字体、屏幕亮度遮罩，全部本地持久化
- **6 套阅读主题**：米黄 / 羊皮纸 / 护眼绿 / 深棕 / 夜间蓝 / 纯黑 AMOLED
- **自动滚屏**（慢/中/快三档，可悬浮按钮控制）+ 滚到底自动续读下一章开关
- **书签**：记录章节与位置，目录弹窗内「目录 / 书签」双标签管理；目录支持关键字过滤与章节号跳转
- **本章查找**：章内关键字高亮、逐个跳转（↑/↓）；支持导出整本书为 TXT；累计阅读时长统计
- 翻页方式：左右点击热区、方向键、空格/PageUp/PageDown 翻页（到底自动续章）、Esc 返回
- 有声书朗读：系统语音 / 在线百度 TTS / 离线 sherpa-onnx 神经 TTS 三引擎，多音色、语速、逐段高亮、点段落朗读、录音、离线语音包导入导出
- **配套爬虫 `novel_crawler.py` v3.0**：多站点适配、异步并发、断点续传/增量更新、智能编码检测（UTF-8/GBK）、章节分页自动合并、终轮失败补抓与失败清单、TXT/EPUB 双格式导出、关键词搜索、批量清单下载、自定义代理/UA/Referer/Cookie

## 运行

### 浏览器直接运行
用浏览器打开 `index.html` 即可；四种棋的 AI 全部本地计算，断网也能玩。

### 桌面应用（Windows）
```bash
pip install -r requirements.txt
pyinstaller --onefile --windowed --noconfirm --name "妙搭小站" ^
  --add-data "index.html;." --add-data "go.html;." --add-data "chess.html;." ^
  --add-data "xiangqi.html;." --add-data "intchess.html;." ^
  --add-data "gomoku.html;." --add-data "fun.html;." --add-data "airplane.html;." ^
  --add-data "hrd.html;." --add-data "sudoku.html;." --add-data "snake.html;." --add-data "biquge.html;." ^
  --add-data "sokoban.html;." --add-data "2048.html;." --add-data "minesweeper.html;." ^
  --add-data "jump.html;." --add-data "novels_data.js;." ^
  --add-data "sw.js;." --add-data "manifest.json;." ^
  --add-data "icon-192.png;." --add-data "icon-512.png;." snake_launcher.py
```

### 小说爬虫
```bash
python novel_crawler.py -u <小说目录页URL> --build
```
详见 `爬虫使用说明.md`。

## 技术栈
- 前端：HTML5 Canvas、原生 JavaScript（无框架依赖）
- 棋类 AI：围棋 MCTS；中国象棋/国际象棋 Negamax + Alpha-Beta + 迭代加深（PST 评估）；五子棋棋型评估 + Minimax + Alpha-Beta
- 益智：华容道 BFS（连续滑动边，标准 81 步）；数独回溯生成 + 唯一解校验；飞行棋贪心 AI 与完整规则状态机
- 桌面：pywebview + PyInstaller
- 爬虫：Python aiohttp（异步并发）+ BeautifulSoup，标准库 zipfile 生成 EPUB
- 部署：GitHub Pages（PWA）
